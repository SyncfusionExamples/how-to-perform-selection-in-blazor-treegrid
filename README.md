# How to perform selection in Syncfusion Blazor Tree Grid

## Overview

This sample demonstrates selection features available in the Syncfusion [Blazor TreeGrid](https://www.syncfusion.com/blazor-components/blazor-tree-grid) component. The implementation shows how to configure row selection and cell selection, work with different selection modes and selection types, perform checkbox selection, enable toggle selection behavior, and use TreeGrid selection APIs. This sample serves as a practical reference for developers who need to manage record selection workflows in hierarchical datasets displayed within a TreeGrid.

**Documentation**: https://blazor.syncfusion.com/documentation/treegrid/selection/

**Online examples**: https://blazor.syncfusion.com/demos/tree-grid/selection?theme=bootstrap4

## Key Features

- Demonstrates row selection within the TreeGrid component.
- Demonstrates cell selection for individual data cells.
- Shows different TreeGrid selection modes.
- Demonstrates multiple TreeGrid selection types.
- Shows checkbox-based selection for TreeGrid records.
- Demonstrates toggle selection behavior.
- Illustrates usage of TreeGrid selection-related APIs.
- Uses hierarchical parent-child data displayed within a TreeGrid.
- `Client/Pages/Index.razor` contains the primary TreeGrid selection implementation.

## Prerequisites

- Visual Studio 2022 or Visual Studio Code
- .NET SDK compatible with the project's target framework

## How to Run the Project

**Visual Studio 2022**

1. Clone or download this repository.
2. Open the solution file:

   `TreeGridSelectionSample.sln`

3. Restore NuGet packages.
4. Set the startup project
5. Build the solution.
6. Run the application using `Ctrl+F5`.

**Visual Studio Code**

1. Open the repository folder in Visual Studio Code.
2. Open the integrated terminal.
3. Navigate to the repository root.

```bash
dotnet restore
dotnet run
```
